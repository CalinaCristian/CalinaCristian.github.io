# Precise source scenery runtime

The source exports already preserve every scenery source node and exact prepared XY. Runtime previously rendered only the rounded decimetre row. It now consumes precise prepared points only when the source identity, finite point count and each point's decimetre encoding match that exact scenery row. Invalid/misaligned caches and legacy datasets retain the previous decoder. No source node, road record or graph connection is changed.

Null packed widths come from the builder's scenery split occurring before the core-only median/width normalization loop. For an outside two-way road, an undefined median can produce NaN, serialized as null. Some non-null widths also predate literal source width normalization. This runtime correction applies positive unit-aware OSM `width` directly, followed by an accepted same-source review already retained in a width cache. Literal width wins, including widths below the old 4.4 m minimum. Resolved source lateral extents are reused only when their width matches. Unknown widths retain the previous fallback and stay explicitly labelled estimates. No source lane count is changed or inferred to make a building fit.

Current source-district controls cover all 5,637 exact scenery pieces available in this checkout and 94 literal-width pieces. For example, Floreasca private source `w289331891` now draws its literal 5 m width in scenery as well as in the core. Tests include invalid source caches, unit conversion, narrow literal widths, accepted/rejected review identity, literal priority, cached asymmetric extents and unchanged unknown-width/legacy behavior. The test accepts `--data-root=/path/to/game/data` for the final combined all-eight snapshot.

`world.stats.scenerySource` records precise/fallback piece counts, literal/review/estimate width counts, exact resolved widths with provenance and every rejected source cache. Existing skipped scenery bridge semantics remain unchanged. Browser atlas/context evidence follows the combined freeze; these pure controls are not visual acceptance.
