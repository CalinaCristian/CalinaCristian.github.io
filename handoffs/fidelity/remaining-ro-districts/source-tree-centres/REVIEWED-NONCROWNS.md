# Reviewed non-crown source corrections

A registered aerial comparison exposed automatic crown candidates on yellow airport paint. Exact georeferenced crops confirmed the error. These source corrections remove only individually reviewed non-crowns from the active aerial input, retain every removed raw candidate with its original index/coordinate/radius, and preserve all mapped OSM trees and actual/ambiguous crown controls. The existing runtime tree-centre guard and its 123/22 baseline diagnostics remain unchanged.

- Otopeni raw automatic candidates: 31,433; individually reviewed non-crowns: 700; active candidates: 30,733. Of these negatives, 380 had reached the compiled source dataset. Compiled tree records change 15,066 → 14,686 (14,673 aerial, 13 OSM). New dataset SHA256: `5e1242d5583db482717545ca0ba99e12b45611c25dcda0c04d1ffe45e084a711`.
- Unirii raw automatic candidates: 40,574; reviewed non-crowns: 23; active candidates: 40,551. Six had reached the compiled source dataset. Compiled trees change 15,764 → 15,758 (14,838 aerial, 920 OSM). New dataset SHA256: `9797d9f5b1a4f2593528ce6c8c4ad04ec38fb953c9770bf32f6d7d5c7c54f26c`.

The two `game/research/trees-bucharest-<district>-review.json` ledgers retain all excluded raw records, 40 m crop pixel coordinates, nominal ground scale, exact official source tile URLs, original input/mosaic hashes, private review-sheet hashes, acquisition date unknown, access/review date 2026-11-08 and classification reasons. No reference imagery is committed. Thirty-five actual or ambiguous positive controls remain, including airport planted islands, woodland/crown edges, yellow/brown real trees and uncertain vegetated drainage strips. Selection regions and a yellow-pixel screen only selected crops for inspection; they never performed blanket exclusions. Twenty-three Otopeni sheets and one Unirii sheet were inspected. No uninspected negative region is promoted.

Rebuilds use the unchanged root437 source compiler (all `tools/osm` files byte-equivalent). Independent `reviewed-noncrowns-check.py` reconstructs every original ordered candidate, verifies its semantic hash, asserts all positive controls remain, compares every mapped OSM tree record and checks that only `trees`, `treeInfo`, `treeCrownRadii` and `treeRetention` change in either compiled JSON. It also asserts the exact 380/6 compiled deltas and zero performance thinning. All building/roof/courtyard/source identities, roads/access/widths/grades, parking, POIs, green rasters and railways remain byte-equivalent. Source raw XML audits are unchanged; the rail/tree source audit is repeated.

This is a bounded manual source correction, not a claim that all automatic crowns have been manually classified. Uncertain shrubs/vegetation and unknown image acquisition dates remain explicit. Native physical rejects remain separate; their current totals must be measured on the final new snapshot. Removing false inputs can advance downstream RNG differently, so the source437 atlas remains honest pre-correction evidence and current renders need an explicit new source/data hash. Final atlas and Street View comparison coverage remain separate acceptance gates.
