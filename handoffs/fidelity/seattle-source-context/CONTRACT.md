# Bounded source context

The schema-1 context asset is separate from existing district/spot source arrays. It carries `sourceCoverage`, input hashes/URLs, a canonical projection `frame`, `nodes` as flat `[originalOSMnodeID,latitudeE7,longitudeE7]`, and an exact deduplicated raw `tags` dictionary. Buildings, ways, areas, coastlines and trees retain literal IDs. Their `n`/`holes` indices preserve original order and closure; ordered original relation members are retained separately. Incomplete relations stay in `unresolvedSourceClosure`. The extractor never creates graph joins or simplifies/offsets a source ring.

`terrain` stores original Float32 numeric elevations as little-endian base64, actual returned GeoTIFF pixel-centre coordinates, separate latitude/longitude steps, units and datum/source provenance. PixelIsArea centres and the server-expanded returned extent are explicit. The requested bbox must not replace the returned grid. No local datum conversion is invented.

The decoder applies literal numeric height/minimum/roof tags and source levels before estimated dimensions. It converts explicit units, keeps raw tags and holes, and never derives metres from `layer`. Original close-up source arrays and authored level anchors remain authoritative. Compressed JSON/cache assets retain readable source/hash metadata and must validate source/profile/terrain signatures before use.

Optional `Ground.sourceTerrain={heightAt,sourceSHA256,basis,transitionM}` continues a small close-up DEM outside its original rectangle. Every in-rectangle query remains unchanged. Only the outside edge blends over one original sample interval, then uses the measured surround. That seam is a model transition, not a measurement. An unknown surround result preserves the legacy fallback and is outside the measured-context claim. This hook is separate from source-water cuts and their actual surviving-triangle floor queries.

The source compiler/decoder/continuation is preparatory. Scene geometry/materials/visibility caches, fresh actual public-app ground/elevated/activity pictures, actual load/budget checks and overview synchronization remain required. Source counts alone do not demonstrate graphics quality. Raw provider XML/raster inputs remain outside Git; the numeric selected sources and hash ledgers remain reproducible within their stated immutable source scope.
