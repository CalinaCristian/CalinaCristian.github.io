It does not change runtime movement, the motor graph, rendered tracks or other source geometry.

The four appended fields are `tramSources`, `tramSourceWays`, `tramRoutes` and `tramSourceNodeTags`. Every rendered vertex retains its original source node ID. Complete source ways retain every original node reference and raw tag; relevant route/master relations retain all raw tags and ordered members/roles. Literal shared source nodes define cached continuation coverage. Coincident coordinates and nearby motor roads do not create joins. Service/status ways remain available for audit rather than silently becoming operating rights. Missing coordinates are represented by null geometry plus original missing IDs; unavailable relation way members are explicit. Direction, access, suspension and grade tags remain literal. No elevation or travel permission is inferred from a road, relation membership, bridge or layer number.

`dataset-identity.json` records full old/new hashes for all six Bucharest datasets. For the four enriched files, the complete original serialized prefix and every old JSON value are unchanged, including `trams`, roads, buildings, scenery, metadata and generated dates. Floreasca and Otopeni are byte-identical as complete files. Only four top-level fields were added. No full rebuild, browser or network request was performed.

`*-metadata-write.json` retains the actual cached-only extraction reports and SHA/byte ledgers for every raw XML input. Sources are the existing Grozăvești, Pipera, Romană and original-district cached tiles. The extractor uses the builder's sorted-file/first-occurrence parser, rejects unmatched or ambiguous render identities, and rechecks every input hash before writing. No selected source record has conflicting duplicate cached content according to the independent XML audits.

`*-independent-audit-final-r2.json` comes from a separate Python XML parser and independently checks every render node/coordinate, original complete way order/tags/geometry, literal-node continuation closure, selected ordered relations and node tags. It checks the old serialized prefix/values/dates and source input hashes too. All four pass. The largest original render quantization errors are 0.066956 m (Grozăvești), 0.056352 m (Pipera), 0.061947 m (Romană) and 0.066067 m (Unirii), within the existing decimetre half-cell diagonal. These measure unchanged old quantization, not moved tracks. Current complete ways have no unavailable coordinates; synthetic controls also exercise explicit missing/invalid coordinate handling. Outside-export route members remain listed, not filled by invented geometry. Route 11's original `Temporary suspended due to rail repair.` notes are preserved.

`cpu-controls-final-r3.json` and its log retain 12 passing controls: clipping/full-way identity, literal-node closure versus a geometric crossing, raw tags and ordered route roles, missing/invalid coordinates and route refs, snapshot isolation before builder decorations, explicit unknown grades/directions, reverse-render/source-direction identity, ambiguous/unmatched rejection, append-only byte/value/date preservation, projection/q and actual changed-builder clipping compared with the baseline compiler. `syntax-checks.json` records syntax and whitespace checks. `tool-integrity.json` pins the executed source tools/parser and data documentation; each independent audit also records its own tool hash.

An early synthetic control failed because JavaScript's `Math.round` returned negative zero while strict array equality expected zero. This occurred before any dataset write. Canonicalizing encoded zero preserves the existing JSON output (`JSON.stringify(-0)` is already `0`); subsequent controls and independent full-data audits pass. That first diagnostic was emitted only in the tool transcript, without a saved raw report. It is not represented as a captured artifact here. Existing intermediate reports remain under `/workspace/integration-qa-evidence/tram-source-metadata/`; the files copied here retain their original names/content and filesystem modification times.
