# Final source-rail observer preparation

This changes proof tools only. No production file or physics controller is edited. Historical reports retain their executed observer copies and exact source labels. No all-eight or900-second native acceptance is claimed by these CPU controls.

The future native publication gate reads `T.initialTramBinding` after source binding and ordinary admission, before attach and at actual first world/main draws. The original `spawnAll` actor assignments are retained explicitly as prerepair input. Constructor tram IDs must match every binding and current actor: missing/failed bindings, unresolved correction, actor loss or nonzero binding RNG are rejected. All191-style source manifests remain exact per actual file counts rather than assuming a fixed count.

The independent pure checker does not import production tram path/grade helpers. It reads literal `tramSourceWays`, rendered `tramSources`/`trams`, ordered route members and stop-node tags. It verifies active source mode, exact source node ordering/coordinates, rendered segment coverage, permitted travel direction, centre station, connected-source axle heading and pitch. Equal coordinates never join unrelated source nodes. Flat height is explicitly the existing estimated local datum; tagged bridges need compatible existing native deck polygons, width coverage and actual height consistency. A layer is never converted to metres. Unresolved native source-grade coverage remains an explicit gate failure.

The final mode gate requires the d77 contract: source rail exposes `publicTram/throughTram`, denies `publicDrive/throughAccess`, and the actual fleet has no car on rail or tram on a motor edge. `initialAdmission.invalidRailModes` must exist and be empty. The earlier a294/235 diagnostic's executed source checker predates this stronger mode API and is preserved separately; it must not be relabelled final mode acceptance.

Source metadata, active/full native rail graph, complete native motor graph with final widths/alignment/ordered adjacency, and source-compatible bridge ribbons are captured once per Traffic instance. Every physical sample records actual tram source pose, route/history, stop state, odometer and crossing claims. `servedRailStop` must identify a real mapped stop; `rail-source-boundary` remains a separate legal terminal stop. These records enable later native dwell/resumption and rail/motor crossing checks. CPU tests and an empty static world do not establish those live gates.

Controls:43 independent positive/negative cases cover missing/false binding/metadata, ID/RNG loss, motor offsets, reverse/wrong parallel track, mode-specific direction overrides and ordered source routes, disconnected body spans, unsupported/wrong deck grades, invented stops and final mode metadata. A separate test agrees with actual d77 native binding/place methods on an isolated CPU fixture and asserts read-only sampling. Global-body tests ensure missing/failed required rail proof becomes a coverage gap while actual-height/body and peer checks continue.

No-tram districts report that limited fact explicitly. Their empty native binding is not evidence for source rail movement, mapped-stop dwell, bridge handling or crossing ownership elsewhere. Native high/full population, source/static clearance, actual emitted body intervals, stop/resume and crossing motion still require the final combined source and a separate native run.
