# US district capture replay

These tools live outside the served source archive. Run one heavy browser at a time. They use actual game rendering and controls; the measured source inputs are not modified by a capture.

Completed frozen capture sources:

- Bellevue street walk: `4198996ab142e3496c9224478eb8cd1aced676fb`.
- SeaTac native facade diagnosis and isolated model studies: `02387aba6eaa01bf77161496554f3af31558e9bf` (same frozen runtime/data plus the separately tested terminal facade detail).

The full SeaTac walk, both atlases and final native controls use the released combined runtime revision `4378317f3fcdccc886d6c7c1ed092ee15d95db8a`. Retain every collection's actual source SHA; an earlier completed walk is never relabelled as a newer atlas/runtime.

Create a read-only working snapshot with `git archive <commit> game public package.json`. The expected dataset SHA256 values are `24c27cbd160167836c254a1b6eafbeeb569df9744faf936d52892a9747a9fe46` for Bellevue and `3c36cd6dc569eb172936f730464d263943380354c8bc444c254f9de6f62c6171` for SeaTac. Capture manifests retain exact source/tool/image hashes; a source refresh requires a new archive and provenance.

1. Plan the atlas with `node tools/aerial/plan-game-grid.cjs --root=<snapshot> --out=<atlas> --city=seattle --district=<id> --commit=<40-character-sha> --locations=<locations.json>`.
2. Capture with `node handoffs/fidelity/us-districts/tools/capture-atlas-final.cjs --root=<snapshot> --out=<atlas> --city=seattle --district=<id>`, then run `python3 tools/aerial/validate-game-grid.py --out=<atlas>`. All north-up cells intersecting the exact core and analytic 600 m ring are required. The extra context cells are separate. The temporary fog/depth override makes this a technical atlas, not a player drone proof.
3. For the street walk, set `FIDELITY_CAPTURE_ROOT=<snapshot>` and invoke `capture-walk-final.cjs --city=seattle --district=<id> --views=<final-poses.json> --streetview --season=auto --w=640 --hgt=400 --quality=high --cache=<private-cache> --out=<walk> --source-commit=<40-character-sha>`. The runner validates the immutable original source way/layer/name at each sampled street position and remaps only the runtime edge index. Panorama metadata does not provide altitude; overlapping surfaces remain flagged. The season follows the reference metadata month.
4. `python3 make-walk-sheets.py <walk>` creates paired review sheets from the actual game/reference images. An optional second argument selects `camera-poses-progress.json` for ongoing inspection. Sheet generation checks image integrity but does not claim visual review. Record the exact pose IDs actually inspected, inspect every final pair and atlas cell, and examine material findings at full resolution.
5. Run `node controls-final.cjs <snapshot> <out> <40-character-sha>` for native chapter driving, foot/office/return-to-car, public-deck traversal, drone controls and high-quality traffic/mirror hotspots. `drone-edge-final.cjs` has the same arguments and records actual controlled flights to the 150 m exterior game boundary. Its initial open-sky foot placement is an explicit fixture; the flight is native. Normal fog, camera depth, collision and flight limits remain enabled. The control run uses each district's configured busy traffic hours. SeaTac also drives the full actual chapter route with native completion enabled, recording every completion position and any recovery placement; continuous completion requires reaching the actual objective without recovery. The boundary flight records requested and achieved height above actual ground separately, including any collision-limited descent.
6. `node parking-canopy-final.cjs <snapshot> <out> <40-character-sha>` repeats every surface car's full lot/court/building/sidewalk/support clearance and independently measured stall-bearing checks. It retains exact dataset/tool/image hashes and the actual scenery-source bridge ledger. Its overhead parking camera is a technical inspection, separate from player drone flight.
7. Only after complete image inspection, write `<district>/final-image-review.json` with `atlasFramesReviewed`, `streetWalkPairsReviewed`, `atlasSourceCommit`, `streetWalkSourceCommit` and `streetWalkReview`, and retain `street-walk-coverage.json` from the metadata survey. `python3 publish-game-comparisons.py <repo> <id> <scratch-root>` requires full validated ledgers and verifies each collection's actual source commit separately. It publishes game images/thumbnails and official reference URLs/dates. Reference imagery and copyright strings are excluded from the repository output.

The source metadata plan contains 762 available SeaTac poses and 426 Bellevue poses. The scope is compiled public nonvirtual, nontunnel roads excluding service, motorway, motorway_link and trunk_link; it does not claim private-airfield, indoor or full-ring street coverage. Retain missing/provider/duplicate counts from the metadata survey separately. A completed source audit or an inspected comparison does not establish photographic identity or resolve unknown source heights, unsupported roofs, ambiguous road levels, estimated dimensions or game-map boundary presentation.
