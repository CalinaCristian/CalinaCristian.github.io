### Source rail paths (2026-11-09 integration contract)

`world.data` exposes source rail metadata independently of the motor graph. Keep the existing `data.trams` delta-encoded render runs and every other existing dataset field unchanged when adding metadata. `tramSources` is parallel to those runs: `{sourceId:'w…', nodeIds:[original source ID per rendered vertex], tags:{all original way tags}}`. `tramSourceWays` stores complete selected ways as `{sourceId:'w…', nodeIds:[complete original references], tags:{all original tags}, points:[delta coordinates using the dataset's existing q]}`. `tramRoutes` preserves relevant relations as `{sourceId:'r…', tags:{all original tags}, members:[{type,ref,role}]}` in original member order. `tramSourceNodeTags` maps tagged selected source node IDs to all their original tags, including rail signals, crossings, access and elevation.

The rail runtime builds separate directed paths from these source records. Join only identical source node IDs, retain vertices and explicit rail direction/access/status/grade tags, and preserve unavailable coordinates or height constraints as unresolved. A nearby road, geometric crossing, road median or motor-road one-way rule never creates rail connectivity or rail travel rights. Existing physical vehicle/pedestrian/static guards and shared crossing reservations still apply. The motor graph and source/rendered track XY remain unchanged; shared modeled grades may change track/support elevation. Metadata and focused path controls do not establish native tram placement, intersection movement or complete district acceptance; those require separate combined tests.

Rail graph edges expose tram eligibility (`publicTram`, `throughTram`) separately from motor access (`publicDrive:false`, `throughAccess:false`). Traffic/admission use the explicit rail-mode legality helper, and must reject a non-tram actor on a rail edge. Optional `world.tramGrade(way,{a,b,index,len})` supplies the shared model used by both physical rail sampling and rendered rail/support geometry: `{known,ya,yb,heightAt?,basis,estimated,provenance}`.
