## Contracts (keep in sync; update here first)
### World (`world.js`)
- `await buildWorld(city, renderer, { district } = {})` → `world`; without `district` loads the legacy corridor JSON `game/data/<city>.json`; with it loads `game/data/<city>-<district>.json`.
- `world.graph.{nodes, edges}` (main strongly-connected network), `world.allEdges`, edge fields: `id, a, b, dirx, dirz, len, nx, nz, name, type, lanesF, lanesB, lanes, oneway, laneW, median (negative on one-way), wR, wL, halfW, sidewalk, maxspeed, speed, tram, bridge, tunnel, layer, toll, busLane, roundabout, drivable, virtual, ya, yb`.
- Lane centre: lateral offset right of centreline `median/2 + laneW*(i+0.5)` (mirror for b→a).
- `world.nearestEdge(x, z, filter?, maxR?)`, `world.edgesInBox(...)`, `world.roadHeight(x, z, { y, edge } | edge?)`, `world.surfacesAt(x, z)`, `world.onRibbon(x, z, r)`, `world.ribbons`.
- `world.buildings` (+ `.query(x, z, r, cb)`), `collideBuildings(list, x, z, r, y?)` export, `world.walls[] {ax,az,bx,bz,y0a,y1a,y0b,y1b,nx,nz,kind,edge}`.
- `world.pois[] {id, kind, label, brand, x, z, doorX, doorZ, cv, interactive, ...}`; CV stop ids: `rosetti, upb, gts, luxoft, db, arnia, uipath-buc, otopeni, seatac, uipath-bel`.
- `world.lamps[] {x,z,h,rot,y}`, `world.lampHeadMesh`, `world.vegetation {treeCrownMeshes, treeTrunkMeshes, deciduousMask, grassMaterials, groundMaterials, roofMaterials}`.
- `world.trafficProfile(hour, { cls, weekend })`, `world.audit({max})`, `world.devCheck()`, `world.spawn {x,z,heading,y}`, `world.scale`, `world.bounds`, `world.district`, `world.city.{center,timeZone}`.

### Render (`render.js`)
- `new Renderer3D(canvas, {quality})`, `.renderer`, `setScene(scene, camera, env, {sky, units})`, `setPlayer(p)`, `setClock({date,lat,lon,timeZone,override,timeScale})`, `setLamps(lamps,{headMesh})`, `setVegetation(v)`, `setHeadlights(bool|null)`, `setWeather(kind|null)`, `setSeason(s|null)`, `setLampLightsEnabled(b)`, `frame(dt)`, `resize(w,h)`, `setQuality(q)`; state `phase, sunElevation, nightLights, headlightsOn, weather, stats`; callbacks `onNightLights, onWeatherChange, onThunder`.
- (2026-11-07, render) Lighting: tone mapping is AgX (`new Renderer3D(canvas, { toneMapping: 'aces'|'neutral' })` to opt out); ambient is a `THREE.LightProbe` (`r3d.probe`, SH of sky + sunlit walls + ground bounce) instead of a hemisphere light in the scene: scenes must not add their own hemisphere/ambient lights (setScene removes them). Optional `env.ambientCity` (0..1 share of walls near the horizon, default 0.5; parks/open spots ≈ 0.15), `env.groundAlbedo` (0.15), `env.wallAlbedo` (0.3). **Night-lit materials**: any material with `material.userData.nightEmissive = <emissiveIntensity at full night>` (and an `emissive` colour / `emissiveMap`) found in the scene at `setScene`/`setVegetation` (or listed in `vegetation.nightMaterials`) gets `emissiveIntensity` eased 0 → value with the dusk/dawn switch (0 by day). (2026-11-07, render) **Fog = aerial perspective**: `scene.fog` stays a `THREE.FogExp2`, but render.js replaces three's fog chunks: `density` is the ground-level extinction coefficient (3.912 / visibility m, from the weather; `r3d.weather.visibilityM`), applied by view distance with a 1.1 km haze scale height (tall landmarks keep contrast), colour = horizon sky. Linear `THREE.Fog` (office) unchanged. `env.edgeM` (or a spot env `fogFar ≥ 2500`) sets a minimum haze that hides a scene's content edge; `env.fogFar` < 2500 (city envs) no longer sets the fog. Tree-crown hook: crowns patched only if their material has `#include <begin_vertex>` / `<color_fragment>` (Lambert/Standard; ShaderMaterials are skipped), local position in metres. Weather/season patch targets: materials named `road`, `junction`, `markings` or meshes `road|junction|ground|marks i,j` (wet + puddles + lamp reflections + snow), `groundPlane`/`landuse`/`paved-areas`, `grass`, `roofs`, instanced `treeCrowns …`.

- (2026-11-07, cockpit-ui) `makeCockpit().userData.viewFor(aspect) → { fov, yaw, pitch, eye }`: driving view per viewport aspect (landscape: fov 72, no offsets; portrait: up to fov 92°, yaw −9° (right), eye offset (+0.07, +0.05, +0.2) m) so the cluster and nav screen stay in view; player.js adds the speed zoom / look offsets on top (spec 17 Requests).
- (2026-11-07, cockpit-ui) **NPC fleet** (`vehicles.js`): `makeVehicle(kind, color, opts = {})` — same contract (forward −z, ground y 0, `userData.length/width/setLights/flash`) plus `userData.height`, `kind`, `city`, `transit` (`'bus'|'trolleybus'|'tram'|null`), `setBrake(on|null)`. `opts.city` = `'bucharest'|'seattle'` (plates EU/WA, police livery, `bus` alias; default = `setFleetCity(cityId)`, call it on city load). `opts.instanced: true` → the group holds **no per-car meshes**: all instanced vehicles of a kind (+ far LOD) in a scene are drawn by shared `InstancedMesh`es (1 draw call per kind × LOD, CPU frustum + distance culling, near ≤ 70 m / 140 m for > 7 m vehicles, far = ~100–170-tri model), filled in a `THREE.Scene.prototype.onBeforeRender` hook (chained; do not replace `scene.onBeforeRender` on scenes that hold instanced vehicles). Callers keep moving / hiding / re-parenting the groups as before; brake lights are automatic from the motion (decelerating or stopped after moving; `userData.parked = true` disables; `setBrake(true|false)` forces, `null` = auto). Kinds (`VEHICLE_KINDS`): cars `compact-sedan` (4.36 m), `sedan` (4.85), `hatch` (4.28), `estate` (4.69), `small-suv` (4.34), `crossover` (4.60), `suv` (5.05), `ev-sedan` (4.72), `minivan` (5.17), `pickup` (5.89), `van` (4.36), `delivery-van` (5.93 × 2.6 m high), `truck` (8.9), `taxi`, `police`; transit `stb-bus` (12 m), `trolleybus` (12 m, poles to 5.6 m), `tram` = `tram-v3a` (27 m, 3 sections), `tram-imperio` (36 m, 4 sections), `kcm-bus` (12.2 m), `kcm-artic` (18.3 m), `bus` (city alias). ### Landmarks (`landmarks.js`)
- `LANDMARKS[] {id, city, name, lat, lon, rotation, osmNames, footprintRadius (legacy: Seattle halved), radiusM (real m), backdrop?, cvStop?, passing?, hero?, districtOnly?}`; `buildLandmark(lm, ctx)` → `{mesh, collision[{x,z,hw,hd,angle}], triangles, clear, clearM, authoredScale}` or `null` (a `districtOnly` landmark when `ctx.scale !== 1`, i.e. the legacy world).
- (2026-11-06, landmarks) **Real scale in districts**: `ctx.realScale = true` builds Seattle models at 1:1 (`authoredScale` 1); without it they stay squashed by `SEA_SCALE` (legacy, default until spec 22). District mode should pass `realScale: true` and use `lk = data.proj.scale / res.authoredScale` and `R = lm.radiusM * data.proj.scale`; today's `lk = scale / SEA_SCALE` + `footprintRadius` path gives the same 1:1 result and keeps working.
- `cvStop: '<poi id>'` (lincoln → uipath-bel, thelandmark → uipath-buc, europehouse → arnia) / `passing: 'plaza-center'`: the CV POI whose door this model hosts. The suppression radius is chosen so the POI address point falls inside it (→ `poi.landmark`).
- (2026-11-07, landmarks) **Floodlit monuments**: `LANDMARKS[].floodlit = true` (parliament, cathedral, arcul, univ, ateneu, regal, victoria, cec, mnir) builds the model's masonry with the shared material `landmark-floodlit` (Lambert, vertex colours; warm `emissive` scaled per vertex by the stone colour so windows stay dark, dimmed on roofs, fading with height). `material.userData = { nightEmissive: 1.1, nightGlow: 1.1, dayGlow: 0, floodlit: true }`: render.js eases `emissiveIntensity` 0 → 1.1 at dusk (the night-lit materials contract), spots' `setNightWindows` reads the same values. No extra draw call (it replaces the `m` mesh). `buildLandmark(lm, { floodlit: false })` opts out. Consumers should not clone it to add their own emissive (a clone drops the per-vertex shader patch).
- (2026-11-07, landmarks) **Fountain water** (`fountains`): jets / spray crowns / foam rings are one mesh `fountain-jets` (material `landmark-fountain-jets`), the basin water one mesh (`landmark-fountain-water`); both transparent Lambert, animated in the shader (shared time uniform set once per frame from the meshes' `onBeforeRender`), `userData.nightEmissive` = underwater lights (render.js). Running state from the research schedule (`fountainSchedule(date)` export: on May–Oct 10:00–23:00 Bucharest time, Simfonia Apei colour show Fri–Sun 21:00–21:45 May–Sep, drained Nov–Apr); date = `FOUNTAIN_STATE.date` ?? `window.game.r3d.simDate` (or `window.spotDev.r3d`) ?? now; render's season `winter` forces off; overrides `FOUNTAIN_STATE.mode` / URL `?fountains=on|off|show`.
