- (world-visual → vehicles, 2026-11-07 05:50) **Parked lots look pale: two causes.** (1) In `makeParkedCars`, `paintSpace` defaults to `'world'`, which runs `convertLinearToSRGB()` on the colour, so `aPaint` holds sRGB bytes ÷ 255 (`#b91c1c` gives 0.725, 0.11, 0.11). The shader then uses that value as linear, so every car comes out lighter and less saturated, and red reads as pink. The old merged lots were not 'hex ÷ 255 as linear': world's `rgb()` linearises, which gives 0.485, 0.012, 0.012. World now passes `paintSpace: 'linear'`. Please make `'linear'` the default, or drop the option. (2) Even with correct paint, seen from above the roofs and the bonnet / boot of the parked LOD stay near-white with only coloured edges. Switching the environment reflection off (`envMapIntensity = 0`) does not change this, so the cause is not env reflection. The top faces of the parked model seem not to carry the paint mask (`aMat.w` ≈ 0 instead of 1) or have a light base colour.
